# 06 — 薩提爾與貝特森 Satir & Bateson

## 維吉尼亞·薩提爾 Virginia Satir（1916-1988）

家族治療學派專家，NLP 四大導師之一。薩提爾模式（成長模式）是 NLP 高階執行師課程的第一單元。

## 薩提爾的治療信念 Therapeutic Beliefs

核心信念（與 NLP 基本假設高度呼應）：

1. **改變是有可能的** —— 即使外在改變有限，內在改變仍有可能。
   - 呼應 NLP 基本假設「地圖不是實際疆域」

2. **在任何時候，父母都是竭盡所能的做到最好**

3. **我們都擁有讓自己成功的內在資源**
   - 呼應「每個人都擁有改變所需要的資源」

4. **我們有許多選擇**，特別是面對壓力時

5. **治療把重點放在健康與可能性上，不是病態**
   - 目標須著重正向描述

6. **希望是改變的一大重要成分**

7. **人們因彼此相似而連結，因各有差異而發展成長**

8. **治療的主要目標之一是為自己做出選擇**

9. **所有人都是同一生命力的展現**

10. **大部分人傾向選擇熟悉而非舒適的方式**，特別是承受壓力時
    - 班德勒答薩提爾：「人類最巨大的恐懼是死亡。」

11. **問題本身不是問題，應對問題的方式才是問題**

12. **感受是屬於我們的，我們擁有它**

13. **人性本善，想與我們的自我價值感連結，就必須發掘自身內在寶藏**
    - 揭示 NLP 邏輯層次中，自我認同層級的重要性

14. **父母往往重複成長過程中熟悉的模式，即使模式功能不良**

15. **我們無法改變過去已發生的事件，只能改變該事件對我們的影響**

16. **任何應對方式皆是自我價值層次的展現** —— 自我價值越高，應對越健康

17. **過程（process）是改變的途徑；內容（content）則形成脈絡（context）**

18. **表裡一致與高自我價值是薩提爾模式的主要目標**

## 薩提爾模式的四大總目標 Four Major Goals

1. **提增自我價值 Self-Worth**：對自己價值的判斷、信念或感受
2. **協助個案為自己做出選擇** —— 至少考慮三個選擇
3. **協助個案負責任** —— 感受是我們自己的
4. **協助個案保持一致性的和諧** —— 同時接觸個人感受、自己、人類共通性，並接納其存在

## 薩提爾模式下的五種自由 Five Freedoms

1. **自由地看和聽** —— 代替應該如何看和如何聽
2. **自由地說出你的感受與所想** —— 代替如何說、如何想
3. **自由地感覺你想要感覺的** —— 代替應該感覺到的
4. **自由地要求你想要的** —— 代替總是等待對方允許的
5. **自由地根據自己的想法去冒險** —— 代替總是選擇安全妥當

## 成長模式 vs 等級模式 Growth vs. Hierarchical Model

### 等級模式 Hierarchical Model
陷入關鍵字：**角色、定位**
- 老闆/員工、樂觀者/悲觀者、父母/小孩
- 強者與弱者、權威與順從
- 落入比較級、角色與自我認同混淆

### 成長模式 Growth Model
- 人們具有平等的價值
- 角色和身分與地位截然不同
- 角色僅意味著在某一時間、某一段關係的作用
- 感受到愛、自我擁有、對他人的尊重

### 對個體的定義
| 等級模式 | 成長模式 |
|---|---|
| 需要服從規則才能被接納 | 每個人都是獨特的 |
| 人生來就有邪惡的潛能 | 能由內部力量來定義自己 |
| 被期望像別人一樣思考、感受、行動 | 整合與尊重、相似與差異 |
| 透過競爭、評價、模仿達到外部標準 | 通過合作、觀察、分享 |
| 忽視或否認認知與感受的差異 | 清晰表達感受，接納差異 |

### 保險銷售的等級模式陷阱
業務員常陷入的等級模式：
- 「客戶是老闆，我要討好」→ 失去專業威信
- 「我是業務員，比專業人士矮一截」→ 無法與律師、醫師級客戶對話

**進入成長模式**：業務員不是乞討者，也不是話術機器。他是一個**在財務保障領域擁有專業，願意與客戶平等討論的夥伴**。

### 互動的要素 Ingredients of an Interaction
薩提爾模式中打破自動化的關鍵：
1. 當下的 VAK 是什麼？
2. 我賦予 VAK 的意義是什麼？
3. 意義帶給我的感受
4. 對我的感受的批判
5. 我如何防禦它？（投射、否認、忽略）
6. 家庭的生存規則

## 冰山理論 Iceberg Model

薩提爾的冰山：人的行為只是冰山露出水面的一小部分，水面下還有：
- 行為
- ─ 水面 ─
- 應對方式（討好、指責、超理智、打岔、一致）
- 感受
- 感受的感受
- 觀點
- 期待
- 渴望（自我價值、被愛、歸屬）
- 自己（精神面）

### 保險銷售的冰山洞察
客戶說「我不需要保險」—— 這只是行為。水面下可能是：
- 感受：焦慮、不被理解、防備
- 觀點：「保險=被推銷=我被當成傻瓜」
- 期待：「我希望被尊重、被看見」
- 渴望：安全感、掌控感
- 自己：「我是一個能保護家人的人」

**高階業務員不處理行為層次，處理的是水面下。**

## 次人格 Parts

薩提爾提出的概念，班德勒延伸到換框技術。

**潛意識就像一間公司，內部有不同部門（次人格）：**
- 創意部
- 執行部
- 習慣部
- 金錢管理部
- 關係部

每個次人格都有自己的正向意圖。改變不是消滅某個次人格，而是與它溝通、整合。

### 分段式不一致與次人格
若對方在不同情境中表現不一致 → 存在不同次人格。
- 客戶與業務員面談時很積極（A 次人格）
- 回家與配偶討論時變保守（B 次人格）
- 這兩個次人格都有正向意圖，需要整合

## 貝特森 Gregory Bateson（1904-1980）

英國人類學家，出生於生物學者世家。貢獻橫跨人類學、心理學、控制論、家庭治療、系統理論。1956 年正式提出**雙重束縛理論**。是 NLP 四大導師中最具學術深度的一位。

### 貝特森的重要理論
- 生物學、人類學背景
- 控制論 Cybernetics 三階段的推進者
- 心智生態學 Ecology of Mind
- 邏輯類型理論 Theory of Logical Types
- 雙重束縛 Double Bind

## 貝特森的基本假設

1. **所有經驗都是主觀的** —— 同一件事對不同人產生不同內在體驗
   - 「地圖不是實際疆域」源自貝特森

2. **心智過程是差異的變換** —— 差異所到之處，都是心智系統的範圍

3. **關於差異的訊息需要能量** —— 能量流動造成差異、差異造成訊息

4. **整體大於部分之和** —— 系統的結構與部分的連結產生湧現

5. **原則上，只用單一的數量解釋任何模式皆為不可行 It is impossible, in principle, to explain any pattern by invoking a single quantity.**
   - 必須多視角觀察所有訊號：訊息、後設訊息、脈絡、框架、溝通、後設溝通

## 心智生態學 Ecology of Mind

心智系統總是包含在更大的心智系統裡。

### 基本單位
- 訊息 Information
- 脈絡 Context
- 邏輯類型 Logical Type
- 後設訊息 Meta-Message
- 差異 Difference
- 意像或資訊

### 控制論三階段 Three Stages of Cybernetics
- 第一階段：工程學（機械控制）
- 第二階段：貝特森、瑪格麗特·米德等（社會科學、家庭系統）
- 第三階段：貝特森 1976 年（心智生態學、整體系統）

## 生態控制煙圈 Ecological Control Ring

貝特森理論的應用：建立可自動修正、自動展化的控制系統。

### 建構步驟
1. 選定控制範圍（脈絡：銷售循環、公司報告、愛情循環…）
2. 鑑別循環中可作為控制的溝通元素：**差異**與**訊息**
3. 建構控制煙圈第一階段假設
4. 驗證控制煙圈假設
5. 建構第二階段反饋假設
6. 驗證第二階段模型
7. 整體控制煙圈模型建立（導入差異與訊息）
8. 實施控制

### 優化控制系統的四個問題
1. 當前系統是否為自動修正系統？若否，如何轉化？
2. 當前控制範圍的有效邊界為何？邊界外有哪些重點？
3. 當前控制系統的脈絡為何？是否有更具效率的脈絡？
4. 如何優化使之更具生產力、貢獻性、價值性？

### 保險銷售的生態控制煙圈
把「一個客戶的生命週期」視為一個生態煙圈：
- 陌生接觸 → 信任建立 → 成交 → 服務 → 轉介紹 → 新的陌生接觸
- 每個階段的「差異」和「訊息」決定煙圈是否持續運轉
- 不優化任一環節會讓整個煙圈死掉

## 邏輯類型理論 Theory of Logical Types

訊息存在不同的邏輯層次，混淆層次會產生困擾。
- 符合條件的邏輯類型 → 產生有效框架
- 框架錯置 → 形成矛盾、雙重束縛

## 雙重束縛 Double Bind

兩個互相矛盾的訊息同時傳遞，對方無論怎麼做都錯。例：母親口頭說「我愛你」但肢體語言排斥 → 孩子無論靠近或遠離都錯。

### 保險銷售的雙重束縛（正向運用）
米爾頓模式中有**治療性的雙重束縛**：
- 「您是今天開始規劃，還是下週開始？」
- 兩個選項都是「開始」
- 不是操控，而是在對方已經認同「要開始」的前提下，幫他聚焦在**何時**而非**是否**

### 破解客戶的雙重束縛
客戶有時會陷入矛盾：
- 「我想為家人規劃，但我不想被當肥羊。」
- 業務員要幫客戶分離這兩個命題：規劃 ≠ 被當肥羊；謹慎檢視 ≠ 抗拒規劃

## 薩提爾 × 貝特森 × NLP 的連結

- **薩提爾**：個人與家庭層次的改變（冰山、次人格、成長模式）
- **貝特森**：系統與脈絡層次的改變（心智生態、控制論、差異）
- **NLP**：把兩者的智慧打包成可執行的技術

**在保險銷售中**：
- 個案（客戶個人）= 薩提爾
- 家庭系統（配偶、父母、子女）+ 市場生態 = 貝特森
- 執行師用來介入的技術 = NLP 其他章節

### 保險銷售的整合應用
一個高端客戶的決策不只是他個人的（薩提爾冰山）—— 還涉及他在家族中的位置（家族治療）、他所處的產業循環（貝特森控制煙圈）、他對整體環境的感知（心智生態學）。

**頂級業務員的視角**：不只看客戶這個人，看的是客戶身處的整個系統。
