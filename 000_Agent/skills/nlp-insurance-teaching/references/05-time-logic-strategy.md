# 05 — 時間線、邏輯層次、策略 Time-Line, Logical Levels & Strategy

## 時間線 NLP Time-Line Therapy

時間線是潛意識對時間在空間中的投射 —— 人類感知時間是以空間概念呈現。空間中投射出一條貫穿過去、現在、未來的潛意識線條。

### 個人時間線導出步驟
1. 兩人一組，站空間中央
2. 找到「每天都會發生但沒有情緒的事件」（如刷牙）
3. 依序問：「昨天那件事適合放在哪個位置？」記錄
4. 過去找 4-5 個時間點；未來找 4-5 個時間點
5. 問：「這些時間點用一條線串聯起來，它的材質會是什麼？多粗？有沒有穿過自己？」

### 時間線呈現的意義
- 光束、麻繩、鐵鍊…材質反映當事人的內在狀態
- 線沒穿過自己 → 可能感到壓力、抽離
- 線在面前攤開 → 對過去有自信

### 三種常見的時間線型態

**類型一**：結合現在，往未來看
- 過去 → 結合現在 → 未來（箭頭向前）
- 適合：有重大過去傷痛、想朝目標前進者（創業者、有明確目標者）

**類型二**：抽離現在，環視資源
- 過去 ← 抽離現在 → 未來
- 適合：對現狀感到壓力者，或從事設計、策劃需整合大量資源者

**類型三**：結合在現在聚焦
- 過去 ← 結合現在 → 未來（聚焦在現在）
- 適合：短期衝刺者，準備考試、從事研究

### 改變個人歷史 The Change Personal History Process
處理過去創傷引發的重複負面模式。

流程：
1. 找出不愉快經驗，引發觸覺感受
2. 設置一個觸覺心錨（鎖住那個觸覺感受）
3. 建立時間線（類型一）
4. 持續啟動心錨，請個案沿時間線**往過去退**，直到再次感受到相同觸覺
5. 放開心錨，記錄該時間點發生什麼
6. 重複第 4-5 步，找到最早出現該感受的時間點
7. 從時間線抽離出來，看著過去的自己，找出當時需要的資源
8. 帶著資源（卓越圈）進入時間線，以顏色渲染整條時間線往未來走
9. 未來模擬

### 保險銷售中的時間線應用
- 客戶對保險有抗拒 → 很可能源自過去某個事件（父母被保險坑過、自己曾聽親戚抱怨）
- 不是要客戶忘記那件事，而是**讓那件事不再綁架現在**
- 帶客戶看他的時間線，找到那個受困時間點，給予資源（今天的資訊、今天的法規、今天的你）

### 時間線破冰話術（銷售應用）
- 業務員：「您願意花 30 秒，跟我做一件事嗎？請您想像在您面前，有一條代表您人生的線 —— 過去在一邊，未來在另一邊。您會把過去放在哪個方向？…好，那 20 年後那個完成所有人生規劃的您，會在哪裡？」
- 接下來引導：「那個 20 年後的您，回頭看現在的您，會想跟您說什麼？」

## 邏輯層次 The Logical Levels Model

**羅伯·迪爾茲 Robert Dilts** 基於貝特森的邏輯類型理論發展。人類思考、想法、話語皆可在邏輯層次上歸類。

### 六層級（由低到高）

| 層級 | 名稱 | 代表提問 |
|---|---|---|
| 6 | 精神面 Spiritual | Who else? 為誰服務？ |
| 5 | 自我認同 Identity | Who? 我是誰？ |
| 4 | 信念/價值觀 Beliefs & Values | Why? 為什麼？ |
| 3 | 能力 Capabilities | How? 怎麼做？ |
| 2 | 行為/情緒 Behavior | What? 做什麼？ |
| 1 | 環境 Environment | When/Where? 何時何地？ |

### 上三層 vs 下三層
- **下三層**（環境、行為、能力）：影響力較弱
- **上三層**（信念、自我認同、精神面）：影響力較強

**上層解決下層的問題，下層無法解決上層的問題。**

### 辨認言語中的層級
- 「我最近想學鋼琴」→ 能力層級
- 「我剛才扶老太太過馬路」→ 行為層級
- 「我覺得我天生就是一個不值得被愛的人」→ 精神面層級

## 邏輯層次的操作：超級催眠系統

### 向上催眠（建立框架）
B 說出下三層級話語，A 辨識後用「呼應-引導」引到上三層級。
- B：「我剛才扶老太太過馬路。」（行為）
- A：「扶老太太過馬路，您真是一個體貼的人。」（引到自我認同）
- 多次反覆，建立對方「體貼」的自我認同框架

### 向下解除（降低框架）
B 說出上三層級話語（可能是限制性信念），A 用引導降到下三層級。
- B：「我覺得我天生就是一個不值得被愛的人。」（精神面）
- A：「許多人在得到幸福前都跟您有相同的遭遇。」（降到環境層級）
- 降低此想法對 B 的影響

### 保險銷售的邏輯層次應用

**識別客戶在哪一層講話，對症下藥**：
- 客戶說「我沒錢」（環境）→ 不要跟他在環境層級爭辯（他永遠能說沒錢）→ 引導到信念層級：「您是覺得錢是花在別的地方更有意義嗎？」
- 客戶說「我這種人不需要保險」（自我認同）→ 強力的框架 → 呼應並提升到精神面：「聽您這樣說，您是為別人著想的人。那家人對您來說意味著什麼？」

**向上歸類成交公式**：
- 環境（今天簽這份保單）→ 行為（每月繳 5,000）→ 能力（您有能力負責這個決定）→ 信念（您相信家人的安全比什麼都重要）→ 自我認同（您是個負責任的丈夫/父親）→ 精神面（您用行動活出對家人的愛）

### 邏輯層次的轉換（完整技術）
在地板上依序排列六個層級位置。A 引導 B 一層一層前進，在每個層級停留並回答問題。
- 自我認同層級：「請用一個隱喻代表你自己。」（例：一片葉子、天使）
- 精神面：「在這隱喻之上還有誰？身為此隱喻的你，為誰而服務？」（例：天空就是雲朵的高層）

## 迪士尼策略 Disney Creativity Strategy

華特·迪士尼的創意策略 —— 在視覺、聽覺、觸覺三種觀點間切換。

### 三種角色
- **夢想者 The Dreamer**：無限可能、創意發散
- **實踐者 The Realist**：可行性、實際操作
- **評論者 The Spoiler**：批判、找問題

### 保險銷售的迪士尼策略
客戶做決定時讓他輪流進入三個角色：
- 夢想者：「如果這份規劃完美執行 20 年，會是什麼景象？」
- 實踐者：「要達成這個結果，每月要怎麼繳？有沒有實際困難？」
- 評論者：「這個計畫的風險在哪？最糟情況是什麼？」

三個角色走完，客戶自己就把決策完成了。

## SCORE 模式 SCORE Model

- **S = Symptom 狀態**：目前的狀態
- **C = Cause 原因**：產生症狀並使持續的原因
- **O = Outcome 目標**：所欲之狀態
- **R = Resources 資源**：（有時放在第三位，協助轉變的資源）
- **E = Effect 影響**：目標達成後的整體平衡

原型可參照 ROSB。

### 保險銷售的 SCORE
- S：現在的保障缺口 / 財務焦慮
- C：為什麼會有這個缺口？（過去沒人提過、過往被誤導）
- O：希望 5 年後的保障配置
- R：現有收入、公司福利、家人支持
- E：達成後，家庭財務、睡眠品質、自己面對風險的從容感

## TOTE 模式 TOTE Model

心理學家 George Armitage Miller & Karl H. Pribram 在 1960 年發表。人類行為的基本回饋策略：
- **T = Test 測試**
- **O = Operate 執行**
- **T = Test 再測試**
- **E = Exit 結束**

任何有效策略都遵守 TOTE 循環：測試當前狀態 → 執行動作 → 再測試 → 達標則結束。

### 保險銷售的 TOTE
業務員的成交流程：
- T1：客戶現在對方案有 80% 認同（測試）
- O：補充一個理賠案例（執行）
- T2：再觀察是否達到 90% 認同（再測試）
- E：提出締結

## 大腦策略 Strategy

結構完整的策略須符合：
1. 目標有明確表象呈現
2. 使用到三個表象系統
3. 策略中沒有兩點間的迴圈
4. 每個迴圈都有出口
5. 用最少的步驟達成目標
6. 地圖趨近實際疆域
7. 沒有不愉快的感受

### 策略註記法
例：小明的感動策略：
**Ve → Ki+ → [(Vr → Ki) Loop] → Ad → Ki+ → Ke**
- Ve：看朋友傳來的簡訊（外部視覺）
- Ki+：心頭很溫暖（正向觸覺）
- [迴路]：回憶聚會畫面 → 心情很好
- Ad：告訴自己要珍惜緣分（內在對話）
- Ki+：幸福感
- Ke：回傳簡訊

### 保險銷售的策略導出
導出客戶的「購買決策策略」：
- 客戶如何做出重大購買決定？看、聽、還是感覺？
- 導出策略後，按他的策略順序呈現方案

## NAC 神經鏈調整術 Neuro Associative Conditioning

**安東尼·羅賓 Anthony Robbins** 依循 NLP 理論發展。透過改變大腦內在神經鏈連結，改變舊習慣或創造新習慣。

### 六步驟
1. 決定真正想要的目標，鑒別什麼阻擋達成
2. 找到改變槓桿：不改變的最大痛苦 vs 改變的最大快樂
3. 終止限制性模式（用強烈誇張的舉動打破慣性）
4. 創造替代性神經連結
5. 強化新連結（視覺化、重複）
6. 檢測新神經鏈

### 保險業務員的 NAC 應用
目標：每天固定打 10 通陌生電話
- 不改變的痛苦：業績落後、家人失望、夢想推遲
- 改變的快樂：成交、收入、成就感
- 終止舊模式：看到電話就拖延 → 立刻大聲說「我要服務更多家庭！」
- 替代行為：拿起電話前先做一個觸覺心錨啟動
- 強化：每天睡前視覺化明日成功的畫面

## 快速恐懼症療法 Fast Phobia Cure

（與 VK 分離類似，詳見 04-framing-reframing.md）

主要步驟：電影院雙重抽離 → 黑白靜止畫面 → 播放 → 結束時畫面轉彩色並倒轉播放 → 加入聽覺嘰喳聲 → 反覆 5-7 次 → 未來模擬。

**保險銷售應用**：業務員對「被拒絕」的恐懼、對「上台發表」的恐懼 —— 都可以用快速恐懼症療法處理。
