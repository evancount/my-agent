# 02 — 親合感與語言模式 Rapport & Language Patterns

## 呼應與引導 Pacing and Leading

催眠大師米爾頓·艾瑞克森：「**呼應就是催眠 Pacing is hypnosis.**」

呼應可以將兩個不同的「個體」形成一個「循環的系統」。呼應越多 → 催眠越深 → 植入指令越容易。任何缺乏呼應的指令皆無法發生效果。

### 呼應技巧兩大關鍵
- **非口語部分**：肢體動作、肌肉變化、臉部表情
- **口語部分**：說話內容、頻率、語氣、語調

### 呼應技巧兩大方向
1. **表徵的映現 Mirroring**：重複或覆誦對方的口語與非口語訊號，當對方的鏡子
2. **高層級呼應 High-Level Pacing**：給予對方邏輯層次上的呼應（見 05 邏輯層次）

### 催眠循環的運作
當甲方丟出訊號 → 乙方給予呼應 → 雙方訊息頻繁交換 → 循環逐漸擴大 → 形成雙方難以跳脫的催眠系統。

所有回饋關係皆為一種催眠狀態：夫妻、親子、交易、友情。**保險銷售的成交本質上就是建立一個雙方都願意留在裡面的催眠循環。**

### 實戰重點
- 呼應對方的**語速**（急性子不要遇到慢動作）
- 呼應**字尾詞**（客戶說「就是這樣啊」，業務員重複「就是這樣，沒錯」）
- 呼應**姿勢**（客戶翹腳你也翹腳，不是同時翹，而是錯開 30 秒）
- 呼應**主題焦點**（客戶聊孩子就聊孩子，不要急著拉回保險）

## 表象系統 Representational Systems（VAK）

人類接收訊息以視覺、聽覺、觸覺三種方式編碼：

### 三種慣用型
- **視覺型 Visual**：呼吸快、說話快、眼球向上、大量使用視覺詞彙（「你看」、「很清楚」、「一目了然」、「畫面是」）
- **聽覺型 Auditory**：呼吸胸腔、語速中等、眼球平視、使用聽覺詞彙（「聽起來」、「我告訴你」、「你說」）
- **觸覺型 Kinesthetic**：呼吸深長、語速慢、眼球向下、使用觸覺詞彙（「感覺」、「摸得著」、「踏實」、「溫暖」）

### 在保險銷售上的判讀與運用
- 對**視覺型**客戶：拿出彩色 DM、建議書要圖文豐富、指給他看數字變化；「您看，20 年後這個數字會累積到這裡…」
- 對**聽覺型**客戶：用故事、用口述理賠案例；「我跟您說一個我客戶去年的真實案例…」
- 對**觸覺型**客戶：讓他摸到保單、簽名時筆要好寫；「您感受一下，這份保單壓在手上的踏實感，就是您給家人的承諾。」

### 商業策略中的表象系統
飲料包裝用柳橙圖片（V 視覺）引發果汁觸覺（K）、用「5℃、果汁 35%、含果肉」（A 聽覺分析）引發真實喝起來的觸覺。**成功的銷售文案多是 V/A 引導到 K 的感受。**

## 眼球解讀線索 Eye Accessing Cues

藉由眼球轉動方向判別對方的內在過程：

| 方向（以面對對方為準） | 代表內在過程 |
|---|---|
| 左上 | Vr = Visual Remembered 視覺回憶 |
| 右上 | Vc = Visual Constructed 視覺建構 |
| 左平 | Ar = Auditory Remembered 聽覺回憶 |
| 右平 | Ac = Auditory Constructed 聽覺建構 |
| 右下 | K = Kinesthetic 觸覺感受 |
| 左下 | Ad = Auditory Digital 內在對話 |

### 破解迷思
**不是每個人都遵守標準位置**。眼球解讀最有價值之處在於**導出對方的思考策略**。例如某人創造視覺只需要通過感受就完成 → 他的眼球不會往視覺創造走，而是停在觸覺。這本身就是重要資訊。

### 保險銷售的應用
- 觀察客戶被問到關鍵問題時的眼球轉向
- 問「您覺得現在的保障夠嗎？」如果客戶眼球往左下（內在對話）→ 他在跟自己談判
- 問「您信任您現在的業務員嗎？」如果眼球往右上（視覺建構）→ 他可能在編造，或想像某種情境
- 想測客戶是否理性派/感性派：問他最近一次做重大決策，觀察他描述時的眼球方向

## 後設模式 Meta-Model

語言無法完整呈現人類體驗，所以人們透過**刪減 Deletion、扭曲 Distortion、一般化 Generalization** 三種過濾方式建立內在地圖。後設模式反向操作，還原深層訊息。

### 三種過濾法
- **刪減**：「我不舒服。」→ 哪裡不舒服？為什麼？
- **扭曲**：「他們都討厭我。」→ 你怎麼知道他們討厭你？
- **一般化**：「保險都是騙人的。」→ 所有保險？騙你哪一塊？

### 後設提問的關鍵
- 主詞（誰？）
- 動詞（做了什麼？）
- 受詞（跟誰有關？）
- 情境/時間

### ⚠️ 重要警告
後設模式會**嚴重破壞親合感**，所以使用時要先有大量的 R（親合感）作為緩衝。否則客戶會覺得你在質問他。

### 貪食蛇技術
當對方不斷無理責備你，用後設模式回應中斷他的責備策略：
- 對方：「你什麼都做不好！每次都這樣！做事做一半、交辦都聽不懂！」
- 你：「您說我什麼都做不好，具體來說是哪件事？您說我每次都這樣，請問具體是哪幾次？」

保險業務員面對客戶無理謾罵時可用此技巧切斷對方的情緒迴圈。

## 米爾頓模式 Milton Model

**米爾頓·艾瑞克森 Milton H. Erickson（1901-1980）** 為 20 世紀最偉大的首席心理治療師。米爾頓模式是後設模式的反向 —— 故意使用刪減、扭曲、一般化的模糊語言，讓對方的潛意識自行填入內容。

### 核心原則
- 模糊 = 涵蓋所有可能 → 讓對方投射自己的版本 → 客戶自己說服自己

### 米爾頓模式常用句型
- **命名化 Nominalization**：把動詞變名詞（學習 → 學習經驗；改變 → 轉變）
- **未指定動詞**：「您會知道。」（知道什麼？客戶自己填）
- **未指定名詞**：「許多人發現…」（哪些人？）
- **預設前提 Presuppositions**：「當您開始感受到這份保障帶來的安心…」（預設了「您會開始感受到」）
- **因果連結**：「隨著您深呼吸，您越來越清楚自己真正需要的是什麼。」
- **雙重束縛 Double Bind**：「您是今天開始規劃，還是下週開始？」（兩個選項都是「開始」）

### 米爾頓框架法
若對方正在經歷某情境，可將其經驗與正在經歷的事件以名詞化向上歸類。
- 業務員：「我們現在坐在這裡討論保障，其實就代表了您對家人負責任的愛。」

## NLP 向上 / 向下 / 側向歸類 Chunking

### 向上歸類 Chunking Up
將訊息向上歸類成更大的框架、名詞化。
- 企劃案 → 事業 → 人生成就
- 繳保費 → 承諾 → 對家人的愛

### 向下歸類 Chunking Down
用後設模式還原細節。
- 客戶說「我有在規劃」→ 規劃什麼？（向下還原為具體行為）

### 側向歸類 Sideways Chunking（隱喻／故事）
以同層級的相似方式傳遞 —— 比喻、模擬、隱喻。**催眠指令的傳遞，豐富的感官描述會讓聽者更深地結合。**

保險銷售的側向歸類範例：
- 「買保險就像給人生買備胎 —— 你希望永遠不用上，但沒有它上路你不安心。」
- 「保障就像家門口的防盜系統 —— 不是每天會用，但有事時你會慶幸當初裝了。」
- 「這份年金就像您幫自己種一棵樹 —— 現在每年澆一點水，20 年後乘涼的是您自己。」

## 高層級呼應 High-Level Pacing

映現 Mirroring 是表徵層次的呼應；高層級呼應是在**邏輯層次**（見 05）與**次人格**（見 06）層次上的呼應。真正的資深業務員做的不是鏡像動作，而是呼應客戶的**價值觀、自我認同、精神面**。

例：客戶說「我覺得我不是那種需要很多保險的人」（自我認同層級）→ 低階呼應只會點頭；高層級呼應會說：「聽起來您是很清楚自己是什麼樣的人的人。」（呼應「清楚自己」這個更高層級的自我認同），然後再引導。
